Lesson 8

Correcting for Overcounting

In this lesson, I will explain each idea, read every expression aloud, and then guide you through the practice answer.

When identical objects create repeated counts, divide by the number of repetitions.

Let us start with the key idea.

Key idea.

If n objects include repeated groups of sizes a,b,c, and so on , then the number of distinct arrangements is:

Read the expression as: the fraction n factorial over a factorial b factorial c factorial and so on.

Now let us see why this works.

Proof.

Pretend all repeated objects are different. This gives n factorial . But each final arrangement can be internally rearranged among the identical objects in a factorial b factorial c factorial and so on ways without changing what we see. Divide by that overcount.

Now let us work through an example.

Worked example.

How many distinct arrangements are there of BALL?

Read the expression as: the fraction 4 factorial over 2 factorial equals 12.
