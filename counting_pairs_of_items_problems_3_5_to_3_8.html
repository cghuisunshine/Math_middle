Problem 3.5 Round-Robin Tournament

How Many Matches Do Eight Players Play?

A round-robin tennis tournament consists of each player playing every other player exactly once. How many matches will be held during an 8-person round-robin tennis tournament?

Solution by Counting Player Pairs

Every match is determined by choosing a pair of players. Therefore, the number of matches equals the number of pairs that can be selected from 8 players:

C(8,2) = (8 × 7) / 2 = 28

Why 8 × 7 = 56 Is Not the Answer

Each player has 7 opponents, so 8×7 counts player–opponent listings. However, every match is counted twice:

A plays B
and
B plays A

These are the same match. Dividing by 2 corrects the double count:

(8 × 7) / 2 = 28
Answer: 28 matches
Core idea: An unordered pair has no first or second member. The pair {A,B} is the same as {B,A}.
Problem 3.6 Sums of Positive Integers

Build and Apply the Formula for 1 + 2 + ··· + n

(a) Compute 1+2+3+4.
(b) Compute 1+2+3+4+5.
(c) Compute 1+2+3+⋯+10.
(d) Find a formula for the sum of the first n positive integers.
(e) Compute 1+2+3+⋯+100.

Direct Calculations

(a)1+2+3+4 = 10
(b)1+2+3+4+5 = 15
(c)1+2+3+⋯+10 = 55

Deriving the Formula

Let S be the sum of the first n positive integers. Write the sum once in increasing order and once in decreasing order:

S = 1 + 2 + 3 + ··· + (n−1) + n
S = n + (n−1) + (n−2) + ··· + 2 + 1

Add the two rows. Each column equals n+1, and there are n columns:

2S = n(n+1)
S = n(n+1)/2

Problem 3.7 General Round-Robin Formula

An n-Person Round-Robin Tournament

A round-robin tennis tournament consists of each player playing every other player exactly once. How many matches will be held during an n-person round-robin tennis tournament, where n > 2?

Method 1: Choose Two Players

Each match is a unique pair of players. Choosing 2 players from n gives:

C(n,2) = n(n−1)/2

Method 2: Add New Opponents

List the players one at a time. The first player adds no previously uncounted match. The second adds 1, the third adds 2, and the nth adds n−1:

1 + 2 + 3 + ··· + (n−1)

Using the formula from Problem 3.6 with n−1 in place of n:

(n−1)n / 2 = n(n−1)/2
Answer: n(n−1)/2 matches
Connection: Counting all pairs of n objects and summing 1+2+⋯+(n−1) are two views of the same counting process.
Problem 3.8 Diagonals of Convex Polygons

Count the Diagonals of an n-Gon

A convex polygon is a polygon in which every interior angle is less than 180 degrees. A diagonal is a line segment connecting two non-adjacent vertices.

(a) How many diagonals does a convex quadrilateral have?
(b) How many diagonals does a convex pentagon have?
(c) How many diagonals does a convex hexagon have?
(d) Find a formula for the number of diagonals of a convex polygon with n sides, where n is any positive integer greater than 2.

Derivation by Counting from Each Vertex

  1. From one vertex, there are n−1 other vertices.
  2. Two of them are adjacent vertices, which make sides rather than diagonals.
  3. Therefore, each vertex is an endpoint of n−3 diagonals.
  4. Multiplying n(n−3) counts every diagonal twice, once from each endpoint.
Number of diagonals = n(n−3)/2

Alternative Derivation

Every pair of vertices makes a line segment. There are C(n,2) such segments, but n of them are sides:

C(n,2) − n = n(n−1)/2 − n = n(n−3)/2

Evaluate the Requested Polygons

Answers: (a) 2, (b) 5, (c) 9, (d) n(n−3)/2
Common pitfall: C(n,2) counts every segment between two vertices, including the n sides. Subtract the sides to keep only diagonals.
